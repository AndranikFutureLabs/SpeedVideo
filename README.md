# 🎬 СкоростьВидео

Приложение для настройки и сохранения скорости воспроизведения видео.

## Возможности

- 📁 Загрузка видео (MP4, AVI, MKV, MOV, WebM, FLV, WMV)
- 🎚️ Настройка скорости 10%-300% через слайдер
- ⚡ Пресеты: 0.25×, 0.5×, 0.75×, 1×, 1.5×, 2×, 3×
- 🖱️ Скрол над видео = менять скорость (Shift+скрол = точная настройка ±1%)
- 👁️ Предпросмотр на лету — сразу видно результат
- 💾 Сохранение видео с физически изменённой скоростью через FFmpeg
  - Видео: `setpts` фильтр
  - Аудио: цепочка `atempo` фильтров (поддержка 10%-300%)
- 📊 Прогресс-бар рендеринга

## Как пользоваться

1. Нажмите на зону загрузки и выберите видео
2. Крутите скрол над видео или двигайте слайдер — скорость меняется на лету
3. Запустите видео (кнопка play) и убедитесь что скорость устраивает
4. Нажмите «💾 Сохранить с этой скоростью»
5. Выберите куда сохранить — получите MP4 с физически изменённой скоростью
6. При открытии сохранённого видео его скорость 100% = та, что вы выбрали

## Технологии

- Electron 33 + Vue 3 + TypeScript + Vite
- FFmpeg (ffmpeg-static) для рендеринга
- esbuild для сборки main/preload

## Сборка из исходников

```bash
npm install
npm run build
npm run electron:dev    # запуск в dev режиме
npm run electron:build   # сборка NSIS установщика
```

## CI/CD

GitHub Actions собирает релизы для всех платформ при пуше тега `v*`:
- Windows: NSIS `.exe` установщик
- macOS Intel: `.dmg`
- macOS ARM (Apple Silicon): `.dmg`
- Linux: `.AppImage`
